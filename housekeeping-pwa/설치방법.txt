지출 관리 가계부 (PWA)

1. 이 폴더의 파일을 모두 그대로 웹에 올립니다.
   - index.html, manifest.webmanifest, sw.js, icons 폴더, vendor 폴더
   - https 주소로 열려야 설치와 오프라인 사용이 됩니다. (예: GitHub Pages, Netlify)
   - 파일을 내 컴퓨터에서 더블클릭해 여는 방식(file://)으로는 설치되지 않습니다.

2. 스마트폰에서 올린 주소로 접속합니다.
   - 안드로이드(Chrome): 화면의 "앱 설치" 버튼 또는 메뉴 > 홈 화면에 추가
   - 아이폰(Safari): 공유 버튼 > 홈 화면에 추가

3. 지출 내역은 설치한 기기의 브라우저(로컬 스토리지)에만 저장됩니다.
   - 다른 기기와 공유되지 않습니다.
   - 앱을 삭제하거나 브라우저 데이터를 지우면 내역도 사라지므로 엑셀 다운로드로 백업해 두세요.

4. 앱 파일을 고친 뒤에는 sw.js 맨 위의 VERSION 값을 바꿔서(v1 → v2) 다시 올려야 새 버전이 적용됩니다.

참고: 영수증 자동 인식은 Claude 안에서만 동작하므로 이 PWA에는 직접 입력만 들어 있습니다.
